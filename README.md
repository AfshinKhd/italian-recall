# Italian Recall

Personal Italian (recall + spaced-repetition) web app.

## Use it in two ways

### 1. GitHub Pages
Open:

`https://afshinkhd.github.io/italian-recall/`

Progress is saved automatically in that browser with local storage.

### 2. OneDrive shared progress
Keep a copy of this project in your OneDrive folder and open `index.html` with Chrome, or use the GitHub page.

In **Settings**:
1. Choose **Link progress file**.
2. Select the same `progress.json` stored in OneDrive on each device.
3. Allow read/write access when Chrome asks.

The app always saves locally first, then mirrors/merges progress with `progress.json` when file access is available.

> On phones, this depends on Chrome/Android exposing your OneDrive file through the system file picker. If it is not available, the app still works with browser-local progress.

## Vocabulary

Edit `words.js`, then refresh the page.
